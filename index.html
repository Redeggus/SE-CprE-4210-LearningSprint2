4. Why Does 255 + 1 Become 0?

An 8-bit unsigned integer has only eight binary positions. Therefore, it can represent 256 different values:

28 = 256 possible bit patterns

Unsigned range: 0 → 255

255 in binary: 11111111

255 + 1: 100000000

The result requires 9 bits, but our integer only has 8 bits.

The extra leftmost bit is discarded:
100000000 → 00000000 → 0

5. Signed vs. Unsigned

The same bits can have different meanings depending on how the program interprets them.

For 8-bit integers:

Unsigned range: 0 to 255
Signed range: -128 to 127
